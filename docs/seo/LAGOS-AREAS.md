# Lagos area pages: what we need from you

Every Lagos area you deliver to can have its own page, like
`mrssamuel.com/juice-delivery-lagos/lekki`. These pages rank for searches such as
"fresh juice Lekki" and "juice delivery Yaba".

**The rule that keeps us safe:** a page only goes live when it has real facts that
only Mrs. Samuel knows about that area. Pages that just swap the place name get
penalised by Google, and that can take the whole site down. The website enforces
this: a page can't go live until it has your local facts.

## For each area, answer these (a voice note is fine)

1. **Do we deliver there?** Yes, no, or only for bulk orders.
2. **Fee:** set it in **admin → Zones**, then tell us the zone name. The page reads
   the fee from admin automatically, so if you change the price, the page changes too.
3. **How fast?** For example "orders before 10am arrive by 2pm".
4. **Real local facts.** At least one, and more is better:
   - estates or streets we deliver to regularly
   - offices, gyms, schools or churches that order (only ones happy to be named)
   - events we've supplied there (a wedding at a known venue, a company end-of-year party)
   - anything special: gate access, a pickup point, a regular weekly drop
5. **Any photos** of deliveries or events in that area.
6. **Customer reviews** from that area, if you have any.

When the answers come in, the developer adds them, switches the page to live, and
it appears in the sitemap automatically.
